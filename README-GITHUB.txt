ANDY'S DIARY — GITHUB PAGES + JEKYLL

This is the Jekyll version of your green whimsical diary.

WHAT IS INCLUDED
- Your edited homepage wording and forest decorations.
- Your existing green responsive CSS.
- Jekyll layouts for the homepage and individual diary entries.
- Pages CMS configuration in .pages.yml.
- GitHub Actions workflow to build and deploy the site.

IMPORTANT
The old localStorage editor has been removed from the public site.
The new script only handles the light/dark theme and diary search.
Diary posts are stored as Markdown files in _posts and displayed by Jekyll.

REPOSITORY
Upload the CONTENTS of this folder to the root of your GitHub repository named:
andys-diary

GITHUB PAGES
After uploading, open repository Settings > Pages.
Set the build and deployment source to GitHub Actions.
The included workflow will build and deploy the site when you push to main.

PAGES CMS
After the files are on GitHub:
1. Open https://app.pagescms.org/
2. Sign in with your GitHub account.
3. Install/authorize the Pages CMS GitHub App for ONLY the andys-diary repository.
4. Open andys-diary and choose the main branch.
5. It should read .pages.yml and show Diary entries.

PRIVACY
The website is public and readable by anyone.
Only people with write access to your GitHub repository can edit its content.
Do not add collaborators if you want to be the only editor.
Because GitHub Free requires a public repository for GitHub Pages, the source files (including Markdown diary entries) are also public. Do not publish anything you want to keep private.

POSTS
Pages CMS creates entries in _posts. Each post needs title, date, mood, and body.
